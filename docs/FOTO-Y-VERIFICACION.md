# Foto: verificar antes de leer marcas

La capa de mano solo habla de una marca si la foto la sostiene. Si no se puede verificar, se describe el límite y se calla la interpretación.

## Umbral para leer

Una foto sirve cuando se puede afirmar, con lo que se ve:

- cuál mano es (izquierda/derecha, dominante si el usuario lo dice);
- palma completa o casi, no un recorte de tres líneas;
- luz que no aplaste el relieve (flash frontal de noche suele invalidar color y montes);
- foco suficiente para ver profundidad de las tres líneas madre;
- pose relajada, no puño ni hiperestiro.

Bonus: ambas manos, mismo encuadre, mismo lado de luz, perfil de dedos.

## Qué se puede decir si la foto pasa

- forma, hueso/carne, palacios, recorrido de líneas, islas, cortes, trama;
- cruce con BaZi y números;
- si una marca es nítida, se puede citar la asociación tradicional (incluida la que suena “médica” en tratados o en 手诊 popular) **como asociación de escuela**, no como hallazgo de consultorio.

## Qué no se puede decir si la foto no pasa

- no inventar islas, cadenas ni 米字;
- no afirmar color de 气色 con flash o tungsteno;
- no comparar asimetría entre dos fotos de pose distinta;
- no convertir un borroso en patología.

## Regla corta

Marca no verificable → se nombra el hueco.  
Marca verificable → se describe y se cruza.  
Línea de vida larga o corta → vigor/arraigo, nunca años.
